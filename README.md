⚡ SwiftPay

Fast. Simple. Secure.

SwiftPay is a modern UPI payment app prototype designed to demonstrate the user interface, navigation, payment flows, and financial-management features of a professional digital payment application.

«⚠️ IMPORTANT: SwiftPay is a prototype. No real money is transferred and no real banking or UPI credentials should be entered.»

---

📱 About SwiftPay

SwiftPay is a mobile-first payment application concept featuring:

- UPI-style payments
- Scan & Pay
- Send & Receive Money
- Transaction history
- Bank-account management
- Bill payments
- Recharge
- UPI AutoPay
- Rewards
- Split bills
- Security controls
- Merchant features
- Financial insights

The current version uses demo data and simulated transactions.

🧪 Prototype Architecture

SwiftPay currently uses a simulated payment architecture:

User
  ↓
SwiftPay Interface
  ↓
Demo Payment Engine
  ↓
Processing
  ↓
Simulated Result
  ↓
Receipt / Transaction History

No real bank transaction is performed.

▶️ Running the Prototype

Option 1 — Local Web Server

Open the project using a local web server.

For example:

python -m http.server 8000

Then open:

http://localhost:8000

Option 2 — Static Hosting

The project can be hosted on a static hosting service that supports HTML, CSS and JavaScript.
